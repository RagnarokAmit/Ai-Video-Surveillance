# 🎥 AI Video Surveillance

A browser-based computer vision project that uses a webcam and the
COCO-SSD object detection model to identify objects in a live video feed.

## 🚀 Features

- 📷 Real-time webcam video
- 🤖 Real-time object detection using COCO-SSD
- 🔍 Detection of multiple object classes
- 🖥️ Browser-based interface
- ⚡ Real-time processing

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- TensorFlow.js
- COCO-SSD
- Web Camera API

## 🧠 How It Works

The application accesses the device's webcam and continuously processes
the live video stream.

The COCO-SSD model analyzes each frame and detects objects that it has
been trained to recognize. Detected objects are identified and displayed
on the video feed in real time.

This project demonstrates how a pre-trained computer vision model can be
integrated into a browser-based application.

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project using a local development server.
3. Allow webcam access when prompted.
4. Start the application.
5. Point the camera at different objects and observe the detections.
